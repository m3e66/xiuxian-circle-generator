# 玄纹 · Cultivation Circle Generator

A browser-based generator for cultivation-style magic circles.

## Features

- Ten outer, ten middle and ten inner designs, independently mixed.
- Lotus, Taiji, Bagua, cloud, flame and talisman motifs.
- Repeatable seeds and a 40-design selection gallery.
- Adjustable detail, line width, color and layered animation.
- Transparent white pixel PNG, SVG and animation-sheet exports.
- Chinese and English controls.

## Run

Open `index.html` in a modern browser. No installation or server needed.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**. Save to publish the site.
